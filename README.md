# Platform 65

Website for Platform 65, a train-themed dining restaurant, built with Vite and vanilla JavaScript.

## Features

- Hero and about sections with a train/railway theme
- Parallax background effect
- Gallery of the dining experience
- Fully responsive layout

## Tech stack

- Vite
- Vanilla JavaScript
- CSS3 (custom, no framework)

## Project structure

```
index.html         Main page
style.css            Styling
main.js              Interactions
public/images/       Site and gallery images
```

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview   # preview the production build locally
```
